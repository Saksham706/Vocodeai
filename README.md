# 🏗️ System Architecture

```text
          React Frontend
                 │
                 ▼
      Authentication Layer
       (JWT + Google OAuth)
                 │
                 ▼
        Express.js Backend
                 │
        ┌────────┴─────────┐
        ▼                  ▼
 OpenAI API          Voice Services
        │                  │
        └────────┬─────────┘
                 ▼
             MongoDB
```

---

# ⚡ Request Workflow

```text
1️⃣ User speaks into microphone
              │
              ▼
2️⃣ Speech converted to text
              │
              ▼
3️⃣ Backend receives request
              │
              ▼
4️⃣ AI processes prompt
              │
              ▼
5️⃣ Response generated
              │
              ▼
6️⃣ Text converted into speech
              │
              ▼
7️⃣ User hears AI response
```

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/VocodeAI.git

cd VocodeAI
```

---

# 💻 Frontend

```bash
cd client

npm install

npm run dev
```

---

# ⚙️ Backend

```bash
cd server

npm install

npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside the server directory.

```env
PORT=5000

MONGODB_URI=

JWT_SECRET=

JWT_REFRESH_SECRET=

OPENAI_API_KEY=

GOOGLE_CLIENT_ID=

GOOGLE_CLIENT_SECRET=

EMAIL_USER=

EMAIL_PASS=

FRONTEND_URL=http://localhost:5173
```
